# Extension Icons

This directory should contain the following icon files:

- `icon-16.png` - 16x16 pixels
- `icon-32.png` - 32x32 pixels
- `icon-48.png` - 48x48 pixels
- `icon-128.png` - 128x128 pixels

## Creating Icons

You can create icons using:
1. The existing PWA icons from `public/icons/` (resize as needed)
2. Design tools like Figma, Sketch, or Canva
3. Online icon generators

## Requirements

- Format: PNG with transparency
- Design: Simple, recognizable at small sizes
- Colors: Use the Clerify brand colors (indigo theme)
- Content: Letter "C" or app logo

## Quick Start

Copy and resize the PWA icons:
```bash
# From project root
cp public/icons/icon-128.png packages/extension/icons/icon-128.png
cp public/icons/icon-48.png packages/extension/icons/icon-48.png
cp public/icons/icon-32.png packages/extension/icons/icon-32.png
cp public/icons/icon-16.png packages/extension/icons/icon-16.png
```
